Report a bug

The dashboard already shows the detected runtime state. If something looks wrong or a feature is not behaving as expected, send the device and runtime information so the issue can be investigated.

1

Tap Copy information in the Actions section, then send the copied report along with a short description of the issue to MEOWna.

2

If the problem happens on a release build (the filename does not contain debug), enable DEBUG LOGGING in the WebUI and reboot. After rebooting, copy the information again and send the updated report.
